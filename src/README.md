## xLua General Version

The xLua General Version is dedicated to providing Lua script support in C# environments. Compared to the Unity version, it only removes features such as print redirection to the Console window and Unity-specific script loaders. All other features are retained. For the feature list, please see [here](../Doc/features.md).

## How to Use

Place `XLua.Mini.dll` into your project, and put the corresponding version of the xLua native dynamic library in a path accessible via P/Invoke (e.g., the application execution directory).

## Code Generation [Optional]

`XLua.Mini.dll` interacts between Lua and C# through reflection. For higher performance, you can use code generation.

1.  Configure the types to be generated according to the [XLua Configuration Guide](../Doc/configure.md).
2.  After recompiling, use the provided tool `XLuaGenerate` on the project's compilation output (exe or dll): `XLuaGenerate xxx.exe/xxx.dll`. The generated code will be placed in the `Gen` directory under the current directory.
3.  Create a new project identical to the original and add the `XLUA_GENERAL` macro.
4.  Remove `XLua.Mini.dll`, add the xLua source package (the `Src` directory in the release package), and include the code generated in step 2.
5.  The exe or dll generated by this project is now adapted through code generation.

## Hotfix

For exe or dll files that have already had code generated, use the `XLuaHotfixInject` tool to perform the injection. For detailed usage of the Hotfix feature, please see the [Hotfix Operation Guide](../Doc/hotfix.md).

## Quick Start

~~~csharp
using XLua;

public class XLuaTest
{
    public static void Main()
    {
        LuaEnv luaenv = new LuaEnv();
        luaenv.DoString("CS.System.Console.WriteLine('hello world')");
        luaenv.Dispose();
    }
}
~~~
